# SKL-005 工程文档编写技能

## 定位

`engineering-document-authoring` 把已经明确和批准的事实、决策、范围与证据写成高质量正式工程文档。

## 适用文档

项目总览、产品定义、PRD、架构、技术方案、ADR、Runbook、实验、README、知识文章和 Portfolio。

## 核心原则

- 一篇文档只拥有一个核心问题；
- 当前实现、接受决策、目标设计和未来规划分开；
- 优先图、表、矩阵、时间线和结构化表达；
- 资源与正文组成 Document Bundle；
- 每个图片有紧邻的 AI 可读语义镜像；
- Human-first、AI-lossless；
- Git-first、Feishu-ready。

## 边界

它不从冲突来源中恢复项目真相，不决定 Registry 生命周期，不发布 Feishu，不修改 Context，也不执行 Commit / Push。
