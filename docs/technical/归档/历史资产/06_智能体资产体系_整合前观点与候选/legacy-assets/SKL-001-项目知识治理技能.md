# SKL-001 项目知识治理技能

## 定位

`project-knowledge-governance` 管理正式项目知识的落位、稳定 ID、生命周期、Registry、完整性、检索和 Git → Feishu 单向投影。

## 不负责

- 多源事实恢复和去重：Project Knowledge Synthesis；
- 架构、PRD、ADR 等正文写作：Engineering Document Authoring；
- Context 语义：总控 Planner；
- 冻结文件落库与 Git 操作：Planner Executor Handoff；
- 任务状态、用户 Memory、完整日志或 Secret。

## 核心模型

```text
Approved Knowledge
→ legal placement / stable ID / Registry
→ Document Bundle integrity
→ lifecycle and publication gate
→ Git-first retrieval
→ Feishu overwrite and read-back
```

资源型文档使用 `README.md + assets/`；每张图片立即跟随 AI 可读语义镜像。Feishu Publisher 上传本地图片，但不把媒体信息回写 Git。
