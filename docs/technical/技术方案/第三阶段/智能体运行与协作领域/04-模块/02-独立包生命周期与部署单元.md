# 智能体运行与协作领域｜Package、Service、Process 与 Deployment Unit

## 1. 当前 Agent-owned engineering units

| moduleRef | npm package | kind | Service | Process/Deployment Unit |
|---|---|---|---|---|
| `agent-runtime` | `@ai-agent-platform/agent-runtime` | library/in-process runtime | 否 | 否 |
| `agent-gateway` | `@ai-agent-platform/agent-gateway` | service | 是 | `agent-gateway-process` |
| `agent-product` | `@ai-agent-platform/agent-product` | agent-package | 否 | 否 |
| `agent-controller-dev` | `@ai-agent-platform/agent-controller-dev` | agent-package | 否 | 否 |
| `agent-test-ops` | `@ai-agent-platform/agent-test-ops` | agent-package | 否 | 否 |

外部依赖：

| capability | Owner | current engineering unit |
|---|---|---|
| Browser CREATE/RESTORE/WAKE/delivery | Execution | `execution-browser-extension` + execution runtime flow |
| Public tunnel | Deployment | Dev Tunnel External Resource Module |
| Custom GPT Carrier | Deployment governance + Agent carrier contract | ChatGPT External Resource Module |

## 2. `agent-runtime`

承载 Role Registry、credentials、Worker identity、Collaboration durable state 与 Agent Public API。它作为独立 npm package 被 platform-host in-process 装配，不建立额外 daemon。

## 3. `agent-gateway`

独立 Service/Process。负责 Custom GPT Actions 公网 ingress、role-specific auth、OpenAI protocol/file bridge adaptation、downstream routing 与响应序列化。

它不拥有 Dev Tunnel lifecycle；只 requires `public-ingress` capability。

## 4. Agent Packages

三个角色包各自独立 SemVer、静态 Actions schema、Instructions/Knowledge/Carrier requirements 与 conformance tests。它们是 Agent 定义载体，不是常驻 Service。

## 5. Lifecycle primitives

每个 Module 只声明现实支持的 primitives：

```text
precheck
configure/materialize
status
verify
doctor
upgrade requirement
```

只有真实 Service/Process 才声明 start/stop。Agent Package 不伪造 start/stop。

## 6. Deployment orchestration

Deployment Domain 根据 Module Graph 统一生成 plan/apply/start/verify/doctor/upgrade。Agent Domain 不实现第二套平台部署器。

## 7. Versioning

- 五个 Agent-owned packages 独立 SemVer。
- Role Registry 记录 `registeredPackageVersion`，用于检测 package 与已部署 GPT 配置漂移。
- Gateway/Agent Runtime contract compatibility 必须由 conformance + real integration tests 验证。
- Agent Package 升级若需要人类修改 Custom GPT Web，返回 `ACTION_REQUIRED_WEB`，完成后再 verify。

## 8. 目标仓库结构

```text
packages/
├── agent-runtime/
├── agent-gateway/
├── agent-product/
├── agent-controller-dev/
├── agent-test-ops/
└── ...other-domain-packages
```

Browser Extension 和 Deployment external-resource adapters 位于各自 Owner 的正式 package/module 位置，不进入 Agent package 目录。
