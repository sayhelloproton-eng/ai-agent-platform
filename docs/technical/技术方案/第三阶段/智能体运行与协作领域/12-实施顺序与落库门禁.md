# 15. v0.2 新增：七包生命周期 Conformance Gate

在整平台组合部署前，**原七单元清单中的各实际 Module** 必须通过对应 Owner 的 package/module conformance；Browser 归 Execution，Dev Tunnel 归 Deployment External Resource（ALIGN-008/029）：

```text
agent-runtime
agent-gateway
browser-extension
dev-tunnel
agent-product
agent-controller-dev
agent-test-ops
```

每包必须声明并实现自己支持的标准 lifecycle commands，并允许专有命令。

测试：

- [ ] descriptor 可被 Platform Deployment 发现；
- [ ] unsupported command 明确返回；
- [ ] standard command structured output 稳定；
- [ ] package 自己能完成自己的 setup/config/account/login/bind details；
- [ ] Platform Deployment 无需复制 package-specific implementation；
- [ ] 单包 verify/doctor PASS；
- [ ] 总部署只通过标准 protocol 组合/透传 PASS。
