# 安全边界与稳定性测试计划

## 1. Security Boundary Families

- Identity/Auth：Role Bearer → authenticatedRoleRef；Browser local-platform-token；不信任 body roleRef。
- Filesystem：projectRoot、path traversal、symlink、protected `.ai-agent-platform`。
- Secret：credential/env/token/cookie/private key 不进 Git/Knowledge/Task Markdown/log/browser injected text/output。
- Network：Execution Local 只 deterministic engineering network；Gateway relay 防 SSRF/private/metadata endpoint。
- Browser：stable roleRef+workerRef 与 transient tab/window/content id 分离。
- Approval：Carrier consequential/confirmation 与 Execution Approval 独立。
- Deployment：doctor 默认诊断；mutation 必须通过 repair plan / ACTION_REQUIRED。

## 2. Stability Families

- SQLite transaction/concurrency/WAL/crash reopen；
- idempotency replay/concurrent duplicate；
- single Model lane sustained + FAST/REASON switch；
- runtime queue/timeouts/cancel/restart；
- Browser reload/reconnect/progress gap/runtime stall；
- Deployment interrupted apply/upgrade/resume；
- Gateway transport budget/expired locator/relay TTL。

## 3. 性能阈值规则

只使用冻结文档明确存在的硬限制（例如 Carrier 45s / `<100,000 chars`、File Bridge count/size/aggregate/fetch timeout）。其余 latency/QPS/coverage 不自动发明数值；先建立 baseline 与真实需求相关的回归门。
