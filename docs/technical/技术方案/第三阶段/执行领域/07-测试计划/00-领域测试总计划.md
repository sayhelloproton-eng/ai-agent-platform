## 5. Domain Test Responsibility

- Domain Behavior：只证明本领域状态/invariant/idempotency/concurrency/error/recovery。
- Contract：Provider + Consumer 双侧，runtime schema 不能只靠 TS type。
- Integration：尽量使用真实 storage/serializer/schema/adapter；昂贵外部依赖才 fake。
- Real Acceptance：如果被验收能力就是 Browser/Carrier/Local Effect/Model/External Resource 本身，则不能只 Mock。
- Conformance：只证明平台治理结构，不替代 Domain PASS。
