# 11 · Execution 跨领域接口与依赖矩阵

## 1. 总原则

Execution 只通过 owning domain 的 Public API 获取业务事实。

不直读别的领域数据库，不复制别的领域状态机。

## 2. Matrix

| 方向 | Execution 需要什么 | Owner | Execution 能否修改真源 |
|---|---|---|---|
| Execution → Task | Task/Node/run、worker binding、Node Context、状态校验 | Task | 只能通过 Task Command API |
| Execution → Agent | Role/Worker registry facts、Collaboration message/delivery target | Agent | 只能通过 Agent Public API |
| Execution → Model | `infer(...)` + ReasoningSpec；FAST/REASON/AUTO 为 Model logical modes | Model | 否；只调用 Public inference contract，不选择物理 Provider |
| Deployment → Execution | install/config/start/stop/status/verify/doctor | Deployment | Deployment 管生命周期，不改 Execution 业务语义 |
| Gateway → Execution | Worker Action 执行请求 | Agent/Gateway | Gateway 不执行资源 |
| Browser Driver → Task | Node/worker facts与正式 transition | Task | Extension 不直接写 DB |
| Browser Driver → Agent | Collaboration delivery result | Agent | 通过 Agent API 回写 formal fact |

## 3. Task API 依赖

Execution/Browser 需要概念能力：

```text
getNodeContext(taskId,nodeId)
get task/node current facts
validate task/node/run
read task-level worker binding
formal node transition API（由 Task 定义）
```

Execution 文档不重新命名/冻结 Task Domain 已拥有 API；实际接口以 Task 最新真源为准。

## 4. Agent API 依赖

至少：

```text
list/get registered role
resolve role carrier metadata（包括实际 Custom GPT carrier URL/path；Browser 上层不得自行从名称/slug 猜 URL）
get task-bound worker facts
read pending Collaboration message
report collaboration delivery/result
```

具体 exact API 以 Agent Domain 最新真源为准。

## 5. Model Contract 依赖

Execution 需要的不是“模型 id 操作”，而是统一 Model Public Contract：

```text
infer({ specRef, mode: FAST | REASON | AUTO, input, ... })
getRuntimeStatus()  // 仅在需要查询 Model Runtime 当前可用性时
```

FAST / REASON / AUTO 是 Model Domain 的逻辑推理模式；Vision 是输入 modality / capability requirement，不是独立旧 API。`judgeFast / judgeReason / visionJudge` 仅属实验实现命名，Phase3 normative consumer 不再调用。Execution 不直接选择物理 Provider；Provider moduleRef、active model、串行 lane、加载与路由由 Model Domain 解决。

## 6. Deployment 依赖

Deployment 最终需要知道 Execution packages 的 requirements：

```text
Node 20
SQLite path
projectRoot
browser extension install/load
local runtime port/endpoint
model runtime config refs
logs path
```

但 Execution 不在此文档实现 Deployment Planner。

## 7. Browser Extension 与 Task Driver 的所有权提醒

Task Driver 是 Browser 侧业务驱动机制，但它的每一次判断都必须引用 Task/Agent/Execution 正式事实。

它不能因为“驱动 Task 浏览器流程”就升级成新的 orchestration domain。
