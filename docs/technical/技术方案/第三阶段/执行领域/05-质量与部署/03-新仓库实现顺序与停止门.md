# 14 · 新仓库实现顺序与停止门

> 本项目已决定：五领域架构/技术设计完成后，创建**全新仓库**实施 Phase 3 平台；本文给 Execution 的推荐实施顺序，不要求现在立即编码。

## 0. 原则

- 先合同，再 Runtime，再 Local，再 Browser；
- 每一步都可以独立验收；
- 不把 既有实验实现 非当前基线代码直接当新实现真源；
- 实验资产只有在符合当前 Contract 且重新验证后才可复用；已有代码结构不得反向改变当前架构；
- 任何跨域公共语义变更先走 Contract Change，并更新受影响 Domain 的规范与 E2E。

## 1. Slice X0 — contracts + skeleton

实现：

```text
execution-contracts
execution-runtime skeleton
execution-local skeleton
extension skeleton
```

冻结：tsconfig、runtime validation、base DTO、error/status、Capability IDs。

STOP：`tsc --noEmit` + contract test PASS。

## 2. Slice X1 — Runtime Record / Idempotency / Hard Scope

实现：

- SQLite migration；
- Execution Record CRUD；
- idempotency；
- projectRoot scope；
- basic policy hard rules；
- structured logs。

STOP：E1 core PASS，restart record recovery PASS。

## 3. Slice X2 — Local read-only

实现：File read/search、Git read、Code Query、Process status、safe endpoint。

全部 deterministic。

STOP：真实临时项目 E2 read-only PASS。

## 4. Slice X3 — FAST path + Local mutations

接 Model Public Contract；实现 file write/git commit/package/test/process/network write/shell。

同时实现 Result/Evidence/UNKNOWN recovery。

STOP：E2 full PASS + fault cases PASS。

## 5. Slice X4 — Browser runtime session / binding / observe

实现：

- extensionInstanceId/contentInstanceId；
- handshake/heartbeat；
- transient worker binding；
- observe/screenshot；
- Side Panel basic truth view。

STOP：stale ONLINE/reload receiver 等 既有实验实现 类型缺陷不可复现。

## 6. Slice X5 — CREATE / RESTORE / WAKE

真实 ChatGPT Web E2E。

STOP：existing worker 不 duplicate create；WAKE evidence reliable。

## 7. Slice X6 — Browser writes / permission / UNKNOWN

实现：submit/input/click/action permission/human continuation/verifier/recovery scan。

STOP：E3 PASS + effect boundary fault injection。

## 8. Slice X7 — Task Driver / Collaboration / Observer

接 Task/Agent Public API；实现 Worker Lanes、Collaboration delivery、Progress Gap/Stall、System Observer。

STOP：业务线与 Observer 不互相污染；Observer lowest priority。

## 9. Slice X8 — E4 Reliability

系统性 reload/restart/disconnect 测试。

**E4 不 PASS，不允许进入跨域最终 E2E。**

## 10. Slice X9 — E5 Cross-domain E2E

真实产品 Task 闭环。

STOP：所有 Execution Record / Evidence / Task formal transitions 一致，Side Panel 可观测，日志可追踪。

## 11. 明确不提前实现

在上述 slices 中不得顺手加入：MCP、RAG、plugin registry、scheduler、remote execution、vault、Docker/K8s。
