## 9. 证据解释优先级

当旧脚本 summary 和后续人工/合同复核冲突时，按以下顺序解释：

```text
真实 API / File / Runtime / Git result
> 当前 frozen schema + raw structured output
> 专项回归
> 大型综合 benchmark summary
> 测试脚本自己的 ALL_GREEN 标志
> Chat 中未经证据支持的猜测
```

任何旧文件名里的 `final` / `freeze` 都不能单独证明它仍是当前基线。
