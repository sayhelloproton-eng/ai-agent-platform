# Knowledge Metadata

本目录保存机器可读的资产索引、资产关系和迁移清单。修改正式资产时按需维护；元数据不替代 Git 正文。

Knowledge Projection 不维护逐文件对应表。`docs/knowledge/` 的目录结构整体一对一发布到 Feishu Knowledge Base，并以 Git 内容执行 Overwrite Publish。

`engineering-insights/` 保存工程洞见注册表。它是抽象工程经验的 Git 主记录，不属于 `docs/knowledge/` 发布源；项目复盘、代码、测试和日志只作为来源证据，Skill 本体只保存提炼方法。
