# 技术文档

`docs/technical/` 保存工程实现与维护资料，不参与飞书知识投影。

```text
架构实现/     代码层边界和实现映射
技术方案/     具体问题的工程方案
治理规则/     Agent、文档、Git、审批和安全规则
技术调研/     外部资料、候选方案和证据
工程规范/     仓库、模块、测试和实现约束
运维与事件/   运行、发布、事故和执行记录
迁移计划/     目录、元数据和知识迁移
归档/         superseded 与历史资产
```

机器元数据已经移至根 `platform-registry/`，模板移至 `docs/templates/`。
