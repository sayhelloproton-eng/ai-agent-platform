# 渐进式学习执行计划

## 原则

不按固定周数强行推进，以能力关卡和验收结果决定是否进入下一阶段。

## Gate 0：产品与环境基线

章节：第 00～01 章。

成果：课程目录、环境矩阵、ChatGPT/Codex 能力地图、两种权限模式、根 AGENTS 初稿、配置继承实验。

通过：不再混淆入口、运行环境、上下文和配置作用域。

## Gate 1：Agent 认知

章节：第 02～03 章。

成果：LLM/Agent 对比、生命周期、最小状态机、三步单 Agent 实验。

通过：能判断什么时候不需要 Agent。

## Gate 2：任务与上下文

章节：第 04～05 章。

成果：Task Schema v0.1、Context Pack、Coding Task、上下文规模对比实验。

通过：Coding Agent 无需猜测目标、文件范围和验收标准。

## Gate 3：知识与工具

章节：第 06～07 章。

成果：Git/飞书分工、Feishu 读写实验、MCP/Action/Skill 选型矩阵、Tool Schema。

通过：写操作具备鉴权、审批、验证和日志。

## Gate 4：Coding Agent 闭环

章节：第 08～09 章。

成果：任务、修改、lint/test/build、diff review、状态机、审批与文档更新。

通过：Agent 不直接 push，失败可停止和恢复。

## Gate 5：Runtime 与可靠性

章节：第 10～12 章。

成果：Gateway、Task/Run/Step/Artifact、权限矩阵、Trace、Eval、成本记录。

通过：入口、Runtime、Agent、Tool、Knowledge 解耦且执行可追踪。

## Gate 6：平台与作品集

章节：第 13～18 章。

成果：编排实验、CI、Personal AI Agent System、AI 视频工作流、Demo 与简历。

通过：项目可运行、可复现、可解释、可评估。

## 每次学习会话格式

开场：

```text
当前章节：
当前小节：
已经确认：
待解决问题：
本次不处理：
期望实验：
期望沉淀文件：
```

结束：

```text
本次结论：
证据：
未解决：
项目决策：
需要更新的文档：
下一小节前置条件：
```

一次会话只完成一个可验证问题；困难任务可以拆分，但每次必须留下可继续状态。
