# 文档体系

`docs/` 保存长期文档资产。Git 是唯一真源。

```text
docs/
├── knowledge/   正式知识与飞书唯一发布源
├── technical/   技术方案、治理、调研、运维、迁移和归档
├── learning/    学习过程、教程和来源
├── adr/         正式架构决策
└── templates/   文档模板
```

`context/` 是 Agent 启动上下文，`skills/` 是程序性能力，`platform-registry/` 是系统元数据和关系真源。

修改文档前读取 `docs/AGENTS.md`。
