# Demo Roadmap

1. **Knowledge Demo**：给定任务，生成最小 Context Package；生成 Git Draft 和 Feishu Projection Preview；检测 Drift。
2. **Coding Demo**：ChatGPT 生成 Task Contract，Codex 修改分支并返回测试与 Result，知识资产随 PR 更新。
3. **Video Demo**：输入短故事，生成角色/场景/分镜/Prompt，调用可替换 Provider，记录成本、重试和评价。

每个 Demo 必须有可运行入口、失败案例、测试、架构说明和可量化结果。
