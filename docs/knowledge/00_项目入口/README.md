# 项目入口

## 目录职责

本目录是正式知识体系的第一入口，负责项目总览、平台愿景、当前能力、阅读路径、当前与目标架构以及决策演进。

## 正式资产

| ID | 文件 | 作用 |
|---|---|---|
| CTX-001 | `CTX-001-项目总览.md` | 项目背景、真实演进、当前主线和成功标准 |
| PRD-001 | `PRD-001-平台愿景.md` | 用户困境、长期愿景、近期使命和产品承诺 |
| CTX-005 | `CTX-005-当前能力地图.md` | 基于代码、测试和真实调用的能力与边界 |
| CTX-006 | `CTX-006-知识库阅读导航.md` | 面向不同角色的最小上下文读取路径 |
| CTX-007 | `CTX-007-当前实现与目标架构.md` | 当前真实链路、目标架构和阶段差距 |
| DEC-001 | `DEC-001-架构决策演进摘要.md` | 决策背景、替代关系、影响和证据 |

## 边界

- 实时分支、Commit 和批次状态见 `context/current-status.md`；
- 技术实施见 `docs/technical/`；
- 长期决策见 `docs/adr/`；
- 机器状态、路径和关系见 `platform-registry/`；
- 目录 README 不作为独立飞书正文发布。
