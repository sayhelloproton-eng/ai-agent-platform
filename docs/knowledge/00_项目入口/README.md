# 项目入口

## 目录职责

本目录只回答三个入口问题：

1. 项目为什么存在、长期建设什么；
2. 当前真实完成了什么、距离下一阶段还差什么；
3. 为什么从早期方案演进到当前路线。

产品细节进入 `01_产品体系/`，完整目标架构进入 `04_平台架构/`，知识治理和阅读方法进入知识库根 README 与 `05_上下文与知识系统/`。

## 正式资产

| ID | 文件 | 核心问题 |
|---|---|---|
| CTX-001 | `CTX-001-项目总览.md` | 这个项目为什么存在、建设什么、怎样算成功 |
| CTX-005 | `CTX-005-当前能力与演进差距.md` | 当前真实完成了什么、尚未完成什么 |
| DEC-001 | `DEC-001-架构决策演进摘要.md` | 为什么采用当前架构、治理和协作路线 |

## 推荐阅读

```text
CTX-001
→ CTX-005
→ DEC-001（需要理解决策历史时）
```

只想继续执行当前任务时，优先读取根 `AGENTS.md`、`context/current-status.md` 和目标目录 README，不必完整阅读本目录。

## 聚合记录

本目录曾包含 `PRD-001`、`CTX-006` 和 `CTX-007`。Project Knowledge Synthesis v0.1.0 的首个 Pilot 确认它们分别与项目总览、目录导航和平台架构重复，因此已从正式知识层退役并转入技术归档；稳定 ID 和 superseded 关系继续由 Platform Registry 保存。
