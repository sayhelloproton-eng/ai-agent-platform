# PRT-001 项目故事

项目从“如何让 AI 长期理解一个工程”开始，先处理 Git / 飞书权威冲突、私人上下文、资产索引和 Skill 边界，再进入 AI 编码闭环，最后用 AI 视频业务验证通用 Task / Capability / Workflow 设计。

当前可展示证据包括分层治理、知识资产架构、六个正式 Skill、公开 Wiki 实验、完整仓库迁移、可追踪决策，以及 Custom GPT → Dev Tunnels → Action Gateway → Local Runtime 的真实窄链路。尚未实现的是动态 Task Control、持久执行、自动多执行器编排、AI 视频 Demo 和正式 Portfolio Release，必须明确标为计划。
