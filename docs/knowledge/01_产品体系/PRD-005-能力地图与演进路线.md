# PRD-005 平台能力地图与演进路线

> 平台能力不是平铺功能列表，而是一组有依赖关系的成熟度阶梯。没有通过上一层证据门，不进入下一层的大规模实现。

## 1. L1：知识可恢复——已验证

能力：Git 真源、Context Root、四层文档、README/AGENTS、Knowledge Skill、飞书 Projection。<br>
证据门：新 Agent 能按入口恢复项目；知识发布有预览、确认和回读；冲突以 Git 为准。

剩余债务：旧目录迁移、复杂图资产、Registry 生成索引、自动影响分析和新飞书 Projection。

## 2. L2：安全链路可调用——已验证

能力：Contracts、Auth、Policy、Gateway、Runtime、Dev Tunnel、Custom GPT Action、限流/并发/Timeout。<br>
证据门：本地和公网调用成功；未认证拒绝；TaskResult 校验；测试和日志对应。

剩余债务：静态 Key、开发期 Tunnel、Capability 范围极窄、Cloudflare 远端清理。

## 3. L3：任务可治理——下一阶段

目标能力：

- Goal / Task / Task Version / State；
- expected\_version 和幂等业务命令；
- Event Log、Artifact、Evidence；
- Approval Request / Decision；
- Side-effect Ledger；
- Checkpoint、Snapshot、Pause、Handoff、Terminate；
- Health Event 与 Recovery。

证据门：任务跨 Session 继续；非法状态转换被拒绝；审批与执行版本绑定；失败可恢复或安全终止。

## 4. L4：多 Agent 与多执行器协作——目标设计

目标能力：Agent Profile、两层 Knowledge Pack、Skill Manifest、Capability/Scope、Execution Lane、Branch/Worktree、Codex/Work/其他执行器 Adapter、评估与 Release。

证据门：一个角色可从 Git 重建；两个写入 Task 隔离；执行器替换不改变 Task；角色只能访问授权知识和工具。

## 5. L5：真实业务可证明——未来验证

以 AI 视频工作流完成最小纵向切片：故事输入 → 结构化人物/场景 → 分镜/提示词 → Provider 调用 → 评估/重试 → Demo。<br>
证据门：业务对象稳定、至少一个 Provider 可替换、质量/成本可记录、失败路径可解释、用户能看到完整成果。

## 6. 近期路线图

### 阶段 A：知识基线稳定

00/01 已完成首次落库，后续完成集中修正、其余栏目迁移和全库 Review。

### 阶段 B：Task Control MVP

先定义最小 Task State、Command、Event、Evidence 和内存/文件存储边界；不先做复杂 UI。

### 阶段 C：Approval 与 Recovery

选择一个真实高风险写操作，验证审批、幂等、Snapshot 和补偿。

### 阶段 D：Codex Execution Lane

实现从 Task 到 Codex/Work 的手动或半自动适配，绑定 Branch/Worktree 和结果证据。

### 阶段 E：Agent Profile 与 Knowledge Pack

首期只落地架构师和知识治理两个角色；在现有 Platform Registry 上增加 Agent Profile、Knowledge Pack、Release 和影响关系。

### 阶段 F：AI 视频纵向切片

从“故事文本 → 人物、场景、章节 JSON”开始，再进入分镜和生成模型。

## 7. 优先级原则

- 事实校准先于新增功能；
- 安全边界先于扩大 Capability；
- 控制面先于多 Agent 自动循环；
- 一个真实调用方先于公共抽象；
- 业务纵向切片先于平台横向铺满；
- 代码、测试和 Demo 先于作品集宣传。

## 8. 不进入近期范围

完整通用 SaaS、企业组织管理、生产级多区域基础设施、全自动多 Agent 自循环、根级产品目录、重型工作流框架和未验证的全量观测平台。

## 9. 路线调整触发条件

当发生以下情况，应重新 Review 路线：当前 Tunnel 不可用；OpenAI 产品能力改变 Actions/Apps/Workspace Agent 边界；Task Control 需求被真实业务否定；AI 视频纵向切片暴露新的领域核心；资源/Token 成本超出可承受范围。
