# 产品体系

## 目录职责

本目录维护项目的正式产品体系，回答四个问题：

1. 当前主产品是什么、为谁创造什么价值；
2. 产品能力怎样形成可验证的成熟度；
3. 已计划的上层产品怎样验证；
4. 远期和潜在方向如何与项目、平台能力、Provider 保持边界。

产品文档不保存 Commit、批次和即时进度；这些内容由 `context/` 与 Registry 负责。

## 产品组合一览

| 层级 | 当前定义 | 承诺等级 |
|---|---|---|
| 当前主产品 | `ai-agent-platform`：个人 Agent 工程协作与可信执行平台 | active build |
| 计划验证产品 | AI 视频工作流：首个上层业务纵向切片 | concept accepted / not started |
| 潜在方向 | 可信任务控制台、专业 Agent 资产工作台、项目知识治理工作台、第二垂直工作流 | idea / discovery；非产品承诺 |
