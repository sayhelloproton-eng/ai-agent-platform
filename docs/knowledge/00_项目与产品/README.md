# 项目与产品

## 目录职责

本目录合并原 `00_项目入口` 与 `01_产品体系`，统一回答项目与产品层的五个问题：

1. 项目为什么存在、长期建设什么；
2. 当前真实完成了什么、尚未完成什么；
3. 为什么从早期方案演进到当前路线；
4. 当前主产品为谁创造什么价值；
5. 上层产品、潜在机会和平台能力怎样保持边界。

该合并只收敛 Canonical 知识归属，不改变项目、产品、平台能力和 Provider 的语义边界。

## 飞书投影

- `CTX-001《智能体工程探索录》` 是飞书知识库的独立根首页；
- 它在知识归属上属于本目录，但不在飞书“项目与产品”栏目下重复发布；
- `CTX-005`、`DEC-001` 与全部 `PRD-*` 页面投影到飞书一级栏目“项目与产品”；
- 本 README 只作为 Git / Agent 导航，不作为独立 Feishu 正文。

## 边界

- 即时状态：`context/current-status.md`；
- 阶段顺序：`context/roadmap.md`；
- 完整目标架构：`../04_平台架构/`；
- 产品孵化工作流：`../07_工作流与项目治理/WFL-011-产品孵化与专项业务工作流框架/README.md`；
- 长期决策：`docs/adr/`；
- 机器状态与关系：`platform-registry/`；
- 当前不创建根级 `products/`；
- 潜在方向不等于 Roadmap 承诺。
