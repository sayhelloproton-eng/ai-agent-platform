# REF-002 官方资料来源索引

## 1. 文档定位

本文维护项目使用的官方资料入口和使用原则。外部产品事实具有时效性，正式引用应记录核验日期。

## 2. OpenAI

- ChatGPT Help Center：GPTs、Projects、Memory、Actions；
- OpenAI / ChatGPT Learn：Codex 配置、AGENTS、Skills、MCP 和 Rules；
- OpenAI API 文档：模型、认证与接口。

这些来源用于 CAP、AGT 和 KNO 的产品事实校准。

### 2.1 本轮基础产品与能力核验清单（2026-08-03）

- OpenAI Help：Projects in ChatGPT；
- OpenAI Help：Creating and editing GPTs；
- OpenAI Help：ChatGPT Work and Codex；
- OpenAI Help：Apps in ChatGPT / Plugins Directory；
- OpenAI Help：Memory FAQ；
- OpenAI Developers：Codex；
- OpenAI Developers：Agents SDK、Responses API、Tools、MCP、Handoffs、Guardrails、Results and State。

用途：核验产品入口、配置面、运行位置、上下文边界、工具与权限；套餐、模型、客户端入口和区域可用性仍需执行时重新确认。

## 3. Microsoft

- Microsoft Dev Tunnels 官方文档；
- Dev Tunnel CLI 文档与限制；
- Visual Studio / Azure 开发隧道说明。

Dev Tunnels 当前只用于开发期入口，Public Preview 或资源生命周期事实必须按官方文档复核。

## 4. Cloudflare、Feishu 与 GitHub

- Cloudflare Workers / Tunnel / Wrangler 官方文档；
- 飞书开放平台 Wiki、Docx、Drive 和 OAuth 文档；
- GitHub Git、Actions、Security 和仓库文档。

项目当前不把外部网页内容直接作为 Git 正式事实，必须结合真实实验。

## 5. 引用规则

- 优先官方文档和仓库；
- 记录核验日期；
- 区分当前能力、Preview、计划和历史；
- 不复制大量第三方正文；
- 外部事实变化时触发影响分析。

## 6. 当前事实边界

当前正式知识的关键产品事实已优先使用官方来源校准，但尚无自动来源可用性和过期检查。

## 7. 后续边界

后续为重要外部 Claim 增加 `verified_on` 和 Source Reference，并在 Release 前检查。

## 8. 结论与原则

- 官方来源优先。
- 外部事实必须带时效意识。
- 实验结果与产品声明分开。
