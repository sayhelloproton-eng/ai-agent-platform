## 3. 资产规则

- 复杂图使用正式 SVG，并提供 1800 × 1100 PNG 预览；
- 图片按文档级目录保存在 `knowledge-assets` 分支；
- Markdown 只使用 `asset://`，不使用本地相对路径或外部图床；
- 每张图绑定稳定 `VIS-*` ID、来源文档、目标正文、版本和 SHA-256；
- 正文是事实与边界的完整表达，图片不能成为唯一语义来源；
- 图中必须明确区分当前实现、目标设计和开发期实验边界。

## 4. Git 与飞书

```text
knowledge-rebuild-v2
  └── Markdown + VIS Registry + asset://
                  |
                  v
knowledge-assets
  └── images/**/{VIS-ID}.svg + {VIS-ID}.png
                  |
                  v
Publisher 上传 PNG → Feishu image block
```

Git 中的知识正文和视觉资产元数据仍由 `knowledge-rebuild-v2` 管理；`knowledge-assets` 只保存图片文件。飞书是投影，不反向修改任何 Git 资产。

## 5. 验收

本批图必须经过：

- 来源与层级 Review；
- SVG 安全检查：无脚本、外部资源、事件处理器和 `foreignObject`；
- PNG 尺寸、签名和 Hash 检查；
- `asset://` 与图片分支路径映射检查；
- Registry、Relations、Release 与目标正文一致性检查；
- Publisher 只上传已 Review 的 PNG 预览。
