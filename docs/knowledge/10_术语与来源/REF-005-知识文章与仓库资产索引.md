## 3. 代码与 Skill

- 应用：`apps/`
- 共享包：`packages/`
- 程序性能力：`skills/`
- 仓库脚本：`scripts/`
- 技术实现资料：`docs/technical/`
- 学习来源：`docs/learning/`
- 正式决策：`docs/adr/`

## 4. 控制面

- `context/`：短、小、当前的启动事实；
- `platform-registry/assets.yaml`：资产生命周期；
- `platform-registry/relations.yaml`：跨资产关系；
- `platform-registry/releases.yaml`：批次发布；
- `platform-registry/migrations/`：迁移状态；
- `platform-registry/registries/engineering-insights/`：工程洞见。

## 5. 索引使用

Agent 检索先读 Context 和目录 README，再按资产 ID 与 Registry 关系读取最小必要文档。不要默认全仓扫描或把所有 Markdown 当正式知识。

## 6. 当前事实边界

正式正文、路径迁移、执行治理、十张正式视觉资产和最终六域内容 Review 均已完成；知识重构结果已经合并到 `main`。外部投影尚未开始，飞书发布、发布回读和最终整仓验收需要独立授权。

## 7. 后续边界

路径、状态或关系变化时，优先更新 Registry，再检查本文和栏目 README 是否需要同步。
