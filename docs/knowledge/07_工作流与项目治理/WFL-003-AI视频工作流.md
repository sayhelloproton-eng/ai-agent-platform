# WFL-003 AI 视频工作流

## 目标流程

```text
源文本 → 故事分析 → 角色 / 场景设定集 → 分镜计划
→ 提示词包 → 模型 Adapter → 生成 → 评估 / 重试
→ 成本与证据 → Demo 结果
```

## 设计原则

- 业务对象与视频模型解耦。
- 本地低成本模型承担结构化、检查和路由；昂贵生成调用集中在高价值步骤。
- Character、Scene 和 Shot 保持一致性标识。
- 每次生成保存 Provider、参数、成本、重试原因和结果评价。
