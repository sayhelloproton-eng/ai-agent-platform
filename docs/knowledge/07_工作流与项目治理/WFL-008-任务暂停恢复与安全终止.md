# WFL-008 任务暂停恢复与安全终止

## 1. 文档定位

本文定义任务暂停、恢复、取消和安全终止的状态转换与操作要求。停止不是异常补丁，而是可信 Agent 系统的正式能力。

## 2. 状态转换

```text
running → pausing → paused → resuming → running
running / paused → cancelling → cancelled
running / paused / blocked → terminating → terminated
```

转换由控制面执行，执行器不能仅通过自然语言声称已暂停或终止。

## 3. 暂停

暂停先阻止新副作用，等待安全点，保存 Checkpoint、Lease、资源和待处理 Approval。无法到达安全点时升级为终止或人工接管。

## 4. 恢复

恢复验证版本、输入、环境、权限、审批有效期和外部系统状态。副作用可能已部分完成时先执行回读或幂等检查，禁止盲目重放。

## 5. 安全终止

终止撤销 Lease、关闭可控资源、记录无法补偿的副作用、保存最终 Snapshot 和错误证据。终止不把任务标记为完成。

## 6. 当前实现边界

当前 Gateway / Runtime 具有超时和并发失败，但没有任务级暂停、恢复或终止状态机。执行任务遇到门禁失败时由人和 Codex 手工停止。

## 7. 目标设计边界

目标在 Task Control 中实现暂停与终止命令、Checkpoint、Lease 撤销和幂等恢复；自动重试受次数、时间和风险预算约束。

## 8. 设计原则

- 停止新副作用优先。
- 暂停和完成使用不同状态。
- 恢复前验证版本与外部事实。
- 部分副作用必须先回读。
- 安全终止保留可恢复证据。
