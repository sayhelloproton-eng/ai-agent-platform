# WFL-011 新产品孵化与资产生成工作流

## 1. 文档定位

本文定义新产品从原始机会到形成受控产品资产和开发决策的工作流。该流程生成候选材料，不自动立项或创建空产品目录。

## 2. 流程

```text
Intake
→ Evidence Collection
→ Problem Framing
→ User / Scenario
→ Value and Assumptions
→ Concept Options
→ Capability Gap
→ Experiment
→ Decision Gate
→ Asset Plan
```

## 3. 输入资格

入口至少说明问题来源、受影响用户、期望结果和已知约束。纯技术冲动或单一功能想法可以记录为 Opportunity，但不能直接升级为产品需求。

## 4. 资产输出

根据阶段生成 Product Brief、场景、领域词汇、能力缺口、实验、ADR、Roadmap 和最小纵向切片。未进入设计阶段时不创建代码包和大规模知识目录。

## 5. 决策门

Project Owner 审查证据、战略匹配、成本、风险、可验证性和机会成本，决定继续、补证据、暂停或拒绝。决定进入 Registry 和项目历史。

## 6. 当前实现边界

当前 AI 视频产品概念已经 accepted，但尚未执行完整产品孵化、实验和开发纵向切片。需求流程主要由用户与 Chat 人工推进。

## 7. 目标设计边界

目标以 AI 视频或下一个真实机会试运行本流程，并评估 AGT-009 是否能稳定生成高质量候选资产。

## 8. 设计原则

- 从问题和证据开始。
- 每阶段只生成必要资产。
- 候选状态不等于开发承诺。
- 平台和产品边界在立项前确认。
- Project Owner 保留最终决定。
