# AGT-009 需求与产品孵化智能体

## 1. 文档定位

本文定义需求与产品孵化智能体的候选职责。它帮助整理问题、证据、假设和产品资产，不拥有是否立项、预算投入或进入开发的最终决定。

## 2. 任务目标

将分散需求、用户反馈、市场资料和技术机会转化为结构化 Opportunity、Problem Statement、用户场景、假设、实验和 Asset Plan，并指出证据缺口。

## 3. 输入与输出

输入包括用户陈述、现有产品资产、调研、约束、能力地图和历史决定。输出包括 Discovery Brief、候选价值、非目标、风险、实验计划、所需平台能力和 Decision Request。

## 4. 工作边界

不自行宣布用户需求已验证，不编造市场数据，不创建根级 `products/`，不承诺日期和预算，不直接进入代码实现。需要外部调研时保留来源与时间。

## 5. 协作

与 Product Owner、调研、架构、领域和项目治理角色协作；通过 WFL-011 生成资产，并把需要批准的阶段升级为 Decision Request。

## 6. 当前实现边界

当前由用户与 Chat 承担需求澄清和产品规划，AI 视频产品概念已有 accepted 文档；该智能体尚未创建 Profile、Skill、Knowledge Pack 或 Eval。

## 7. 目标设计边界

目标先以一个真实产品机会执行受控 Pilot，验证输出是否减少需求漂移并提高阶段决策质量，再决定是否发布专用 Agent。

## 8. 设计原则

- 问题证据先于功能方案。
- 事实、假设和建议分开。
- 立项与预算由 Project Owner 决定。
- 只生成当前阶段必要资产。
- 不把候选产品误写成在开发。
