# SKL-004 项目知识综合技能

## 1. 定位

Project Knowledge Synthesis 把多份项目会话、正式文档、执行报告和 Registry 证据综合成可 Review 的知识调整候选。

它解决的是项目级事实恢复、重复与冲突、目标资产落位和退役影响，不是普通摘要，也不替代 Engineering Insight Distillation。

## 2. 输入

- 冻结的来源范围；
- 代码、测试、Context、Registry、ADR 等真值来源；
- 综合目标；
- 稳定 ID、隐私、发布和写入权限约束。

## 3. 输出

- 来源与 Claim 分类；
- 重复组和冲突报告；
- 保留、重写、合并、归档、supersede 或拒绝建议；
- 链接、Context、Registry 和发布影响；
- 质量门与待确认事项。

输出始终是 `candidate_only`。总控 Planner 负责生成正式完整文件，用户进行必要审批，Executor 只做冻结落库。

## 4. 首个 Pilot

v0.1.0 首次用于 `00_项目入口`：六篇正式文章聚合为三篇，阅读导航归 README，重复产品愿景和目标架构内容回归各自领域，旧文章转入技术归档并保留 superseded 关系。

## 5. 当前边界

- 状态：`in_review`；
- 已有 request / result Schema、Validator、Self-test 和真实 Pilot；
- 无自动 Provider、跨仓库索引、批量 Eval、直接写入或 Feishu 发布权限；
- Context 语义维护权仍只属于总控 Planner。

## 6. 与其他 Skill 的关系

- 上游：人工 Review、代码与测试证据、Platform Registry；
- 下游：Engineering Document Authoring、Project Knowledge Governance 与 Planner Executor Handoff；
- 可选下游：Engineering Insight Distillation，用于从已验证事件中提炼可复用工程洞见。

## 7. 验证

```bash
npm run check:synthesis
```
