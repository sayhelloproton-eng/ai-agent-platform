# AGT-008 专业智能体目录

## 1. 文档定位

本文维护专业智能体的目录结构、准入标准和状态含义。目录展示已经定义或计划的角色，不把候选名称误写成可用产品。

## 2. 目录字段

每个条目记录 agent_id、名称、角色、目标用户、主要输入输出、依赖 Skill、Knowledge Pack、Tool、权限等级、Eval、Host、负责人和生命周期状态。

## 3. 首批角色族

规划角色包括：产品与需求孵化、技术调研、架构、工作流、代码实现、测试、代码复审、知识治理、工程洞见、健康治理、项目治理与汇报。是否创建 Profile 由真实任务与复用证据决定。

## 4. 状态含义

```text
candidate → designing → pilot → released → deprecated → archived
```

`candidate` 只表示目录候选；`designing` 表示边界正在定义；只有通过 Eval 和发布记录后才是 `released`。

## 5. 目录治理

新增角色前检查是否可以由现有角色、Skill 或 Workflow 解决。职责重叠时优先合并；被替代角色保留历史和 supersedes 关系。

## 6. 当前实现边界

当前 Registry 已规划 AGT-001～AGT-010，本批形成设计正文；尚无正式 released Agent、Agent Profile 文件或 Host 发布记录。

## 7. 目标设计边界

目标在首个真实专业 Agent 进入 Pilot 后，将 Profile、Eval、Knowledge Pack 和发布状态加入目录，并由 Registry 生成导航。

## 8. 设计原则

- 目录状态必须对应真实证据。
- 角色复用优先于新增名称。
- 候选 Agent 不宣称可用。
- Profile、Skill、Knowledge 和 Host 分别引用。
- 目录由 Registry 生成机器视图。
