# 智能体工程探索录

`docs/knowledge/` 是 `ai-agent-platform` 的正式知识表达层、Agent 可查询长期上下文和飞书唯一发布源。

## 阅读入口

1. [`00_项目入口/`](00_项目入口/)；
2. [`01_产品体系/`](01_产品体系/)；
3. 根据角色进入架构、知识、智能体、工作流、实验或作品集。

## 知识树

```text
00_项目入口
01_产品体系
02_基础产品与能力
03_架构思想与理论
04_平台架构
05_上下文与知识系统
06_智能体资产体系

08_实验与复盘
09_作品集
10_术语与来源
```

## 边界

- Git 是唯一真源；
- 本目录是飞书唯一发布源；
- Technical、Learning、ADR、Context 和 Registry 不直接发布；
- 发布不读取飞书旧正文，不比较、不合并，只按映射逐篇 overwrite；
- 目录中的计划清单不代表文章已经实现。

## 路径收口状态

`00～10` 已成为 `docs/knowledge/` 唯一正式顶层知识树。历史或 superseded 资产移入 `docs/technical/归档/`；工程方案移入 `docs/technical/`。机器路径、生命周期和发布资格以 Platform Registry 为准。
