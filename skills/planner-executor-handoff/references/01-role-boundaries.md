# Role Boundaries

## Chat

Complete before delegation:

- recover repository and environment facts;
- use tools to obtain missing evidence;
- define the goal and why it is current;
- analyze affected files, modules, contracts, tests, Registry records, and external effects;
- choose the implementation approach;
- record rejected approaches when they prevent re-litigation;
- freeze allowed and forbidden scope;
- define validation, evidence, risks, and stop conditions;
- review the real result.

Do not send an executor a vague request to discover the project direction.

## Execution layer

Execute only the frozen contract.

The executor may perform authorized reads and writes, choose equivalent tactical commands when permitted, localize command failures, and report observations.

The executor may not redefine the goal, select a new architecture, expand scope, add dependencies without authorization, reinterpret requirements, or accept its own work.
