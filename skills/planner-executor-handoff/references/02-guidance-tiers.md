# Execution Guidance Tiers

## compact_controlled

Use when the executor has demonstrated reliable scope adherence, honest test reporting, safe local troubleshooting, useful checkpoints, and low tendency to invent facts.

Render complete deterministic analysis with phase-level guidance. Allow equivalent tactical commands, not alternative strategies.

## stepwise_controlled

Use when the executor needs fixed sequence, exact commands and paths, expected outputs, repeated range checks, explicit prohibition of inference, detailed checkpoints, and fixed feedback.

Keep all canonical analysis identical to the compact view.

## Current defaults

- Codex: `compact_controlled`.
- OpenCode with DeepSeek: `stepwise_controlled`.

These are current experience defaults, not permanent brand classifications.

Classify new executors using confirmed user experience, reviewed history, or a small read-only probe task.
