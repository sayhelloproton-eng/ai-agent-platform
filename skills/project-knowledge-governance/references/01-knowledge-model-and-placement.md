# Knowledge Model and Placement

- `context/`: compact current project state owned semantically by the master Planner.
- `docs/knowledge/`: accepted, human-readable long-term knowledge and projection source.
- `docs/technical/`: implementation plans, research, runbooks, migration and operational evidence.
- `docs/adr/`: durable decisions and consequences.
- `docs/technical/归档/`: superseded or historical material retained for evidence.
- Platform Registry: asset identity, lifecycle, relations, projection and implementation evidence.

Do not use long-term documents as a task database, user Memory, secret vault or full trace store.
