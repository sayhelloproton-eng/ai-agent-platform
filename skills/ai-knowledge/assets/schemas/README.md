# Schemas

JSON Schemas for distinct Git Knowledge Architecture assets:

- Context Package and Project Status describe dynamic Agent Runtime Context sourced from `context/`.
- Knowledge Item describes stable Human Knowledge sourced from `docs/knowledge/`.
- Knowledge Event describes evidenced Git asset changes and explicit Projection publication.
- Write Plan represents exactly one Git Update or one separately authorized Projection Publish.

Feishu is a Projection Target. It is not a canonical Knowledge Item source. Schema changes require examples, tests and version review.
