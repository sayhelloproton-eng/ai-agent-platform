# Output and Governance Gates

A valid synthesis proposal must include source inventory, overlap groups, unresolved conflicts, target assets, retired assets, link impact, Registry impact, privacy review and human approval status.

Critical gates:

- scope frozen;
- claims classified;
- current truth reconciled;
- duplicate and conflict decisions justified;
- stable IDs preserved or explicitly retired;
- all cross-references and Registry relations accounted for;
- private or unsupported content excluded;
- result remains `candidate_only`.

The Skill never writes formal assets. Planner authors complete files after approval; Executor applies those files through Handoff and Deterministic Delivery.
