# Context

`context/` 为新 Agent 和开发者提供短、小、当前、可信的项目恢复入口。

## 阅读顺序

1. `project-context.md`：项目为什么存在；
2. `architecture-context.md`：当前实现、目标架构和边界；
3. `current-status.md`：当前基线、完成项、未完成项和下一步；
4. `roadmap.md`：阶段顺序；
5. `knowledge-strategy.md`：Git、Registry、知识包和飞书投影。

## 边界

Context 不保存完整教程、技术方案、历史复盘和动态任务日志。

详细知识进入 `docs/knowledge/`，实现方案进入 `docs/technical/`，决策进入 `docs/adr/`，系统元数据进入 `platform-registry/`。

`current-status.md` 是当前状态的最可信短快照；代码、测试和真实调用证据仍高于文字状态。
